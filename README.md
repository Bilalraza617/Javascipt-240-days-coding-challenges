# JavaScript 240-Day Challenge

This repository is built around the **JavaScript Complete 240-Day Challenge Curriculum**. It is a practice-first learning path that takes you from JavaScript fundamentals to more advanced patterns through daily, topic-based coding challenges.

The goal of the repo is simple: use each day as a small, focused exercise so the concepts become practical through implementation, debugging, and refactoring rather than only theory.

## What This Covers

- JavaScript fundamentals: variables, data types, operators, conditionals, loops, functions, scope, and hoisting
- Core language patterns: template literals, truthy/falsy values, arrow functions, type conversion, and practice problems
- Arrays and objects: methods, destructuring, spread/rest parameters, Maps, Sets, and JSON
- DOM practice: selection, events, forms, validation, local/session storage, and dynamic UI
- Async JavaScript: async/await, fetch API, error handling, REST APIs, and callback-based work

## How To Use

1. Pick the current day from the curriculum.
2. Solve the challenge in a focused file or folder.
3. Refactor the solution after it works.
4. Move to the next day and keep the momentum consistent.

## Repository Purpose

This repo can be used as:

- a personal JavaScript learning log
- a daily coding challenge tracker
- a portfolio-style proof of consistent practice
- a reference for revisiting core JavaScript concepts
